Порядок важен: каждый следующий блок зависит от предыдущего.

## 2. Возможности App ID

На `developer.apple.com` → Identifiers → `kz.asset.focus`.

- [x] **Family Controls (Distribution) — одобрен 2026-08-06.** ✅
      Выдан на аккаунт целиком, покрывает все четыре bundle ID.
- [ ] **Time Sensitive Notifications** — сейчас выключен, и из-за этого
      сигнал о конце фазы приглушается режимами фокусирования, теми

      Проще всего в Xcode: открыть `ios/Prizma.xcworkspace` → цель
      Prizma → Signing & Capabilities → **+ Capability** → Time

      `app.json`, он уже подготовлен и закомментирован в
      `plugins/withLocalNotificationsOnly.js`.

## 4. Цены — по витринам, вручную

**Подписки не входят в автоматическую корректировку цен Apple.**
Автоконвертация завышает бедные рынки в два-три раза, и видно это будет
в конверсии, а не в отзывах. Это самая дешёвая доступная оптимизация и
единственная, которую невозможно сделать за тебя.

|---|---|---|---|---|
| США, Канада | $5.99 | **$29.99** | $79.99 | — база |
| Еврозона | €6.99 | **€34.99** | €89.99 | цена в ЕС показывается с НДС 19–25% |
| Великобритания | £5.99 | **£27.99** | £74.99 | автоконвертация даёт +26% |
| **Казахстан** | 1 490 ₸ | **6 990 ₸** | 17 900 ₸ | ≈18 000 ₸ — цена, при которой не платят |
| СНГ в долларах | $2.99 | **$14.99** | $34.99 | получили бы цену США |

- [ ] Выставить по таблице. Брать **ближайшую доступную точку** из

- [ ] **Availability:** отметить страны вручную. Россия недоступна —
      её витрина не проводит платежи с 2022 года.
- [ ] Проверить там же, какие витрины СНГ выставляются в долларах, а
      не в местной валюте: им нужен пониженный долларовый тир.

## 5. RevenueCat

- [ ] Создать аккаунт **на личный e-mail**: это корневой доступ к
      деньгам.
- [ ] Project → добавить iOS-приложение с bundle ID `kz.asset.focus`.
- [ ] App Store Connect → Users and Access → Integrations →
      **In-App Purchase Key (.p8)** → загрузить в RevenueCat.

      **Скачивается ровно один раз.** Второй возможности нет.

- [ ] Создать **App Store Connect API Key** — через него RevenueCat
      читает статусы продуктов.
- [ ] **App Store Server Notifications V2:** вставить URL от RevenueCat
      в App Store Connect. Полей два, Production и Sandbox — заполнить
      оба.
- [ ] В RevenueCat: **Entitlement** с идентификатором `deep_focus`.
- [ ] **Offering** с тремя пакетами (monthly / annual / lifetime),
      привязать продукты, годовой пометить как default.

Без них подписка получает **отказ по правилу 3.1.2**, и это блокирующий
отказ. Домена у проекта нет — хватит статической страницы на GitHub
Pages, это бесплатно.

- [ ] **Privacy Policy** — обязательна всегда.
- [ ] **Terms of Use (EULA)** — обязателен для авто-возобновляемых
      подписок.
- [ ] Обе ссылки должны открываться **из самого приложения**, не только
      из карточки в App Store. Дай мне два URL — я вставлю их в пейвол.

## 7. Проверка покупок без денег

- [ ] Users and Access → **Sandbox** → создать тестовые аккаунты на
      адресах, **не привязанных ни к одному Apple ID**.
- [ ] Проверять только на устройстве: в симуляторе Family Controls не
      поднимается, а StoreKit ведёт себя иначе.

## 8. К подаче на ревью

- [ ] **App Privacy questionnaire.** Сегодня честный ответ —
      «Data Not Collected»: сетевых вызовов в проекте ноль. С RevenueCat
      это перестаёт быть правдой, анкету придётся переписать. Неверный
      ответ здесь — основание для снятия приложения.
- [ ] **Демо-видео и объяснение в Review Notes**, зачем приложению
      Family Controls. Для Screen Time Apple просит это почти всегда.
- [ ] **Скриншоты и описание** в App Store. Это сейчас важнее любой
      следующей функции: канал бесплатный и единственный.
- [ ] **Соответствие DSA** — до сих пор «на проверке». Без него закрыт
      весь Евросоюз. США не требуют, так что подавать можно и без него.
- [ ] Первый продукт уходит на ревью **вместе с первым билдом**.
      Отдельно, до приложения, его не одобрят.
